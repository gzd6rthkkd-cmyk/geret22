Корпоративний вебсайт торговельного підприємства (курсова робота)

Запуск: відкрийте index.html (сайт) або admin.html (адмін-панель замовлень).
Пароль адмін-панелі (навчальний): admin123

Структура:
  index.html      - сайт: Про компанію, Каталог, Новини, Контакти, кошик
  admin.html      - окрема адмін-панель: перегляд, оформлення, зміна статусу замовлень
  css/style.css   - стилі
  js/data.js      - спільні дані: товари, замовлення, збереження в localStorage
  js/script.js    - логіка сайту: CRUD товарів, пошук, фільтри, сортування, кошик
  js/admin.js     - логіка адмін-панелі
  img/            - фото товарів

Важливо: сайт і адмін-панель обмінюються замовленнями через localStorage.
У Chrome/Edge це працює при відкритті файлів двічі клацанням. У Firefox краще
запускати через розширення Live Server у VS Code (Go Live).

Відкриття у VS Code: open-in-vscode.bat / open-in-vscode.command або corporate-site.code-workspace
